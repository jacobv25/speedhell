## Convergent laws (≥2 lineages independently agree)

**L1 — The place IS the wave.** All three: backgrounds change identity every
10–60 s, and guns bolt onto landmarks — turrets on battleship decks, AA on dam
ledges, waves cued by terrain seams (BRDA#1/#2, Psikyo#4/#9, DDP#3/#4). BRDA
never lets 60 s pass without a backdrop change; Psikyo's M6 runs gorge →
waterfall → dam face → dam crest → outflow in ~76 s. *r5 gave SPEEDHELL
per-section tints + landmark silhouettes; the next level is structural — enemies
mounted ON the landmarks.*

**L2 — Breathers are paid in loot, never in emptiness.** Midboss kills convert
the bullet field to gold, valleys rain items, gold-bar corridors keep hands busy
while threat drops (BRDA#4, Psikyo#8, DDP#8). A blank scroll is a design hole.

**L3 — The boss is a ritual: warn → enter → transform → desperate → receipt.**
WARNING banner (DDP#5), telegraphed entrance over emptied ground (BRDA#9,
DDP: silo-hatch rise), phases as FORM changes — silhouette, movement, and bullet
dialect all change, telegraphed by burn-red (Psikyo#6) — arena restains per
phase (BRDA#6), and a desperation finale that is either a stripped bare core
(Psikyo) or a medley of every earlier vocabulary (BRDA#5, DDP saves its densest
web for the last 20 s).

**L4 — Grade the run with an itemized receipt.** Stage-end tally screens that
teach the scoring system between plays: BREAK boxes ×N (BRDA#10), TIME / GOLD /
SHOOT-DOWN (Psikyo#8), stars × value + bees + No Miss (DDP#8). All three.

**L5 — Author the score route as a line, not a stat.** DDP places every wave
within link-distance of the next and laces popcorn as chain-mortar between
bricks (DDP#1/#2); Psikyo gives every enemy a visible fuse (Psikyo#2); BRDA
escalates by repetition-with-density (BRDA#3). The route must be *playtested as
a route*: next spawn ≈ previous wave's earliest kill + a beat.

**L6 — Strict bullet color castes, with a boss-only dialect.** Two-to-five
families whose roles never trade across the whole game (BRDA#7, Psikyo#3,
DDP#7). Psikyo's version is sharpest: needles = stage, patterned dots = boss —
you can tell "stage or boss?" from bullet shape alone. SPEEDHELL's caste (r59)
is the same idea by source tier, inverted: pink rounds = the stage's common
fire, cyan needles = the special tier (mid/elite/midboss/boss) aiming at you.

**L7 — Destructible parts + point-blank invitations.** Bosses lose turret
groups one by one; the optimal position for at least one attack is directly
under the boss, re-earned against strafing (Psikyo#7, DDP#4/#6). Parts feed the
chain so the boss is score food, not a combo reset.

**L8 — Second loop = bullet-diff.** Same layouts, plus on-death revenge shots —
the player's own mastered habit (speed-kill everything) now fills the screen
(Psikyo#10, DDP loop-2 observation). Cheapest second difficulty that exists.

## What SPEEDHELL already follows (validated by the study)

- **Tempo envelope** — ~100 s stage + 3-phase boss sits at Psikyo's M7/M8 end
  (official clear times 1'11"–2'11"); do not exceed ~2'15" total (Psikyo#1).
- **Fuse economy** — speed-kill windows = Psikyo's "kill it in its entry window
  and it never fires" contract (Psikyo#2). This is the core and it's right.
- **Section grammar** — 8 themed sections with ≤2 reps matches BRDA#3's
  state-repeat-escalate-handoff shape.
- **Release section + midboss cancel-to-items** — L2 partially satisfied
  (cancel wall + item shower exist; the release's last beat should empty out as
  the boss approach, BRDA#9).
- **Color castes** — pink rounds / cyan needles / violet-white player fire /
  gold items (post-r5). Missing half: a boss-only pattern dialect (L6).
- **Place-identity v1** — r5's tints + landmarks answer L1's palette layer.

## Ranked adoption list (gauntlet round candidates)

**R6 — Boss theatre package (highest density of laws: L3, L6, L7, BRDA#6).**
The boss is ~¼ of the run and currently phases without transforming.
1. WARNING banner before the gate; entrance over the emptied release field.
2. Phase = form change: silhouette, movement style, and bullet dialect all
   change; burn-red + explosion telegraph at each handoff (structure exists —
   the 60f armor window).
3. One destructible sub-part per phase that is itself a speed-kill target.
4. Per-phase arena restain (deep blue → red → white-hot; renderer-only).
5. P3 finale as medley-desperation: bare-core rings + both earlier dialects.

**R7 — Stagecraft package (L1 structural, L5).**
1. One set-piece hull ~40–50 % of field width hosting the turret alley — the
   turrets sit ON it; killing its turrets chain-links into a core kill (DDP#4).
2. Release section = loot shower over the boss's approach landmark, ending
   empty (L2 + BRDA#9).
3. Route audit: verify each wave's spawn lands a beat after the previous
   wave's earliest speed-kill (referee metric candidate: chain-hold feasibility
   for the expert bot).

**R8 — Receipt package (L4).**
Stage-clear tally itemizing per-section speed-kills, longest chain, time,
no-miss/no-bomb — teaches routing between runs. Cheap, high-flavor.

**Later / seasoning:** pre-boss countdown meter ticking through s5–s7 (BRDA#8);
one-card boss briefing at run start (Psikyo#9); loop 2 as revenge-dot
bullet-diff (L8 — pairs with the handoff's "harder second loop" item); gold
popup outline + HUD-strip dimming nits from r5's verify critics.

## Identity guardrails (what we deliberately refuse)

- **No slow-curtain primary language** (DDP#9). Enemy fire stays fast, aimed,
  sparse; true curtains only as 5–10 s accents at midboss and boss finale.
- **No CAVE endurance** (DDP#10). Sections stay 10–40 s, boss phases 15–25 s;
  part-destruction does DDP's "structure changes as you win" on a Psikyo clock.
- **Density low, lethality positional** (Psikyo study, passim): 3–8-bullet
  aimed clusters, not walls — the gap between bullets is never the challenge;
  the speed of the decision is.

## Protocol note

Adoption rounds run under the standard gauntlet: referee updates (rubric checks
+ harness evidence for any new surface, e.g. boss-form telegraphs and receipt
legibility become shot targets) land BEFORE builders; 1 builder per package;
2 fresh blind critics to close. Max 3 rounds per surface; Jacob is the brake.
